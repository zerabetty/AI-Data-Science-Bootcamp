# Week 03 - CRM Analytics

## Overview

This week's focus was Customer Relationship Management (CRM) Analytics.

Using real-world retail data from FLO, I analyzed customer purchasing behavior and implemented two widely used customer analytics methodologies:

- RFM (Recency, Frequency, Monetary) Analysis
- Customer Lifetime Value (CLTV) Prediction

These projects demonstrate how data-driven customer segmentation can support marketing strategies, customer retention, and business decision-making.

---

## Learning Objectives

Throughout this module I learned to:

- Perform customer segmentation using RFM analysis
- Calculate customer lifetime value (CLTV)
- Apply BG/NBD and Gamma-Gamma probabilistic models
- Analyze customer purchasing behavior
- Generate actionable business insights
- Build end-to-end analytical workflows using Python

## Projects

### Customer Segmentation with RFM

This project applies the RFM framework to segment customers based on their purchasing behavior.

The workflow includes:

- Data understanding
- Data preparation
- Feature engineering
- RFM metric calculation
- RF scoring
- Customer segmentation
- Marketing strategy recommendations
- Exporting target customer lists

### Customer Lifetime Value Prediction

This project estimates the future value of each customer using probabilistic models.

The workflow includes:

- Data preprocessing
- Outlier treatment
- Customer-level aggregation
- BG/NBD model
- Gamma-Gamma model
- Six-month CLTV prediction
- Customer segmentation based on predicted lifetime value
