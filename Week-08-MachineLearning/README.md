# House Price Prediction

This project focuses on predicting house sale prices using the **House Prices: Advanced Regression Techniques** dataset.

The project covers the complete machine learning workflow, including exploratory data analysis, data preprocessing, feature engineering, regression model comparison, hyperparameter optimization, and final prediction generation.

## Dataset

The dataset contains detailed information about residential properties, including:

- Overall quality and condition
- Living and basement areas
- Garage characteristics
- Construction and remodeling years
- Neighborhood information
- Number of rooms and bathrooms
- Various structural and categorical property features

The target variable is:

**`SalePrice`** — the sale price of the property.

## Project Workflow

### 1. Exploratory Data Analysis

The dataset was examined in terms of:

- Dataset structure
- Numerical and categorical variables
- Target variable distribution
- Missing values
- Outliers
- Relationships between variables and `SalePrice`

### 2. Data Preprocessing

Several preprocessing operations were applied before model development:

- Missing value analysis and treatment
- Outlier analysis
- Rare category encoding
- Label Encoding for binary categorical variables
- One-Hot Encoding for categorical variables
- Final missing value and data type checks

### 3. Feature Engineering

New variables were created to capture additional information about property size, quality, age, and interactions between existing features.

Some of the engineered features include:

- `NEW_OverallGrade`
- `NEW_OverallScore`
- `NEW_TotalSqFeet`
- `NEW_TotalHouseArea`
- `NEW_TotalBathrooms`
- `NEW_HouseAge`
- `NEW_RemodAge`
- `NEW_GarageAge`
- `NEW_Garage*GrLiv`
- `NEW_1st*GrLiv`
- `NEW_TotalFlrSF`

Negative age values resulting from inconsistent year information were also corrected before modeling.

## Model Development

Several regression algorithms were evaluated using **5-fold cross-validation**.

The primary evaluation metric was **Root Mean Squared Error (RMSE)**.

The evaluated models included:

- Linear Regression
- Ridge Regression
- Lasso Regression
- ElasticNet
- K-Nearest Neighbors
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost
- LightGBM
- CatBoost

## Baseline Model Results

| Model | RMSE |
|---|---:|
| CatBoost | **24,027.543** |
| Gradient Boosting | 25,116.029 |
| XGBoost | 27,866.774 |
| LightGBM | 27,928.700 |
| Random Forest | 29,940.289 |
| ElasticNet | 31,634.198 |
| Lasso | 31,733.404 |
| Decision Tree | 36,588.258 |
| KNN | 46,951.088 |
| Ridge | 55,990.522 |
| Linear Regression | 58,533.416 |

The baseline **CatBoost** model achieved the lowest RMSE.

## Log Transformation

A logarithmic transformation was applied to `SalePrice` to reduce the effect of its right-skewed distribution.

After converting CatBoost predictions back to the original price scale, the model achieved:

**RMSE: 25,073.612**

The original CatBoost model therefore remained better in terms of RMSE on the original SalePrice scale.

## Hyperparameter Optimization

Hyperparameter optimization was performed for the strongest boosting models.

| Model | Baseline RMSE | Tuned RMSE |
|---|---:|---:|
| CatBoost | **24,027.543** | 24,279.647 |
| Gradient Boosting | 25,116.029 | **24,368.177** |
| XGBoost | 27,866.774 | **25,280.467** |

Hyperparameter optimization improved Gradient Boosting and XGBoost performance, while the default CatBoost model remained the strongest overall model.

## Feature Importance

Feature importance analysis showed that both original and engineered variables contributed strongly to house price prediction.

The most influential features included:

1. `NEW_OverallGrade`
2. `OverallQual`
3. `NEW_TotalSqFeet`
4. `NEW_TotalHouseArea`
5. `BsmtFinSF1`
6. `NEW_OverallScore`
7. `NEW_1st*GrLiv`

Several engineered features ranked among the most important predictors, indicating that the feature engineering process successfully captured additional information relevant to house prices.

## Final Model

Based on cross-validation results, the **baseline CatBoost model** was selected as the final model.

The model was trained on the complete training dataset and used to generate predictions for the Kaggle test dataset.

The predictions were exported as:

`submission.csv`

## Conclusion

This project demonstrates an end-to-end regression workflow for house price prediction.

Feature engineering produced several highly influential predictors, while model comparison showed that boosting algorithms performed substantially better than linear and distance-based approaches.

Among all evaluated models, the baseline **CatBoost model achieved the best overall RMSE of 24,027.543** and was selected for final predictions.
